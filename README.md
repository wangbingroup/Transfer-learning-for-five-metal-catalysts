# Transfer Learning for Five-Metal Catalysts
This repository contains the data-processing, model-training, prediction, and statistical-analysis codes for the transfer-learning-assisted discovery of five-metal catalysts for Li–air batteries.

## Overview
A multilayer perceptron model was pretrained using single- and bimetallic catalyst data and subsequently fine-tuned using five-metal catalyst data. The fine-tuned model was used to predict the overpotentials of candidate five-metal compositions at different current densities.

## Requirements
The main Python packages used in this project are:
- Python 3.6
- pandas
- NumPy
- scikit-learn
- PyTorch
- matplotlib
- joblib
- tqd
